# 📖 تطبيق القرآن الكريم

تطبيق **القرآن الكريم (Holy Quran)** هو مصحف شامل مصمم ليمنحك تجربة روحانية متكاملة للقراءة، الاستماع، والحفظ — بواجهة عصرية وألوان مريحة للعين.  
يدمج التطبيق بين جمال المصحف الورقي ودقة التكنولوجيا الحديثة.

---

## ✨ المميزات الرئيسية

### 📚 مصحف كامل بجودة عالية
- عرض صفحات المصحف العثماني (604 صفحة) بدقة عالية جدًا.
- دعم التكبير والتصغير وتدوير الشاشة (عرض رأسي/أفقي).
- إمكانية **تحميل الصفحات للاستخدام بدون إنترنت** مع شريط تقدم يوضح النسبة والوقت المتبقي.

### 🎧 الاستماع للقرآن الكريم
- مشغل صوتي أنيق أسفل الصفحة.
- مزامنة تظليل الآية أثناء التلاوة في الوقت الحقيقي.
- قائمة قراء تشمل:
  - مشاري العفاسي  
  - عبدالرحمن السديس  
  - سعود الشريم  
  - ماهر المعيقلي  
  - فارس عباد  
  - أحمد العجمي  
  - علي الحذيفي  
  - عبدالباسط (مرتل / مجود بجودات مختلفة)  
  - المنشاوي  
  - هاني الرفاعي  
  - وغيرهم من أكثر من 35 قارئًا.

### 🔁 التكرار والتحفيظ
- اختر سورة وآيات محددة (من .. إلى).
- حدّد عدد مرات التكرار (1، 3، 5، 10، أو مخصص).
- مفيد جدًا للحفظ والمراجعة اليومية.

### 🌙 الوضع الليلي والذهبي
- تصميم أنيق بألوان دافئة مريحة للعين.
- الوضع الليلي بخلفية داكنة وتدرج ذهبي فاخر.
- تنقل تلقائي بين الأوضاع حسب إعداد النظام.

### 🌍 دعم لغات متعددة
- واجهة متاحة بـ **19 لغة** تشمل:
  - العربية 🇸🇦  
  - English 🇺🇸  
  - Türkçe 🇹🇷  
  - Bahasa Indonesia 🇮🇩  
  - Urdu 🇵🇰  
  - فارسی 🇮🇷  
  - বাংলা 🇧🇩  
  - وأكثر...
- شاشة اختيار لغة سهلة وواضحة مع الأعلام وزر “متابعة”.

### 📖 التفسير
- عرض تفسير الآية من مصادر موثوقة (مثل ابن كثير).
- مشاركة التفسير مباشرة.
- نافذة منبثقة أنيقة دون الخروج من الصفحة.

### ⭐ المفضلة
- حفظ الصفحات المفضلة أو مواقع الحفظ الأخيرة.
- قائمة منظمة لآخر 3 صفحات تمت زيارتها.

### 📂 أقسام مرتبة
- **السور**
- **الأجزاء**
- **المفضلة**
- مع تفاصيل: عدد الآيات، نوع السورة (مكية/مدنية)، رقم الصفحة والجزء.

### 🧭 القائمة الجانبية
تشمل:
- الرئيسية  
- البحث  
- الإعدادات  
- حول التطبيق (مع التاريخ الهجري والميلادي)  
- مشاركة التطبيق ورمز QR  
- تقييم التطبيق  
- روابط لتطبيقات أخرى من المطور

## ⚙️ خطوات البناء (Build)

### 🧩 عبر Android Studio (مستحسن)
1. افتح Android Studio.  
2. من القائمة: `File → Open` واختر مجلد المشروع.  
3. انتظر اكتمال المزامنة (Gradle Sync).  
4. شغّل على جهاز أو محاكي.

### 🛠️ توليد APK يدويًا
من Android Studio:  
> Build → Build Bundle(s) / APK(s) → Build APK(s)
